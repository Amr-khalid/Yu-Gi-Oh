# Yu-Gi-Oh! Mobile Edition — Yugi Reborn (نسخة الموبايل الكاملة)

نسخة موبايل حديثة ومتكاملة من لعبة **Yu-Gi-Oh! Power of Chaos (Yugi Reborn)** مبنية بالكامل في مجلد مستقل (`mobile/`) دون المساس بملفات اللعبة الأصلية.

---

## 🌟 المميزات الرئيسية

1. **يعمل بدون إنترنت (100% Offline)**:
   - اللعبة لا تحتاج إلى اتصال بالإنترنت نهائياً.
   - جميع البيانات والصور مخزنة محلياً داخل التطبيق.

2. **اللعب الجماعي بدون إنترنت (Local Multiplayer)**:
   - **Wi-Fi Hotspot**: يمكن لأحد الهاتفين فتح نقطة اتصال محمولة والآخر يتصل بها واللعب معاً بأعلى سرعة واستجابة.
   - **Bluetooth LE**: إمكانية الاتصال المباشر بين الهاتفين عبر البلوتوث دون الحاجة لأي شبكة.
   - **تزامن تلقائي**: بروتوكول مزامنة ذكي يعتمد على Seed موحد لخلط الدكات ومزامنة الحركات لحظياً.

3. **قاعدة بيانات البطاقات كاملة (1,114 بطاقة)**:
   - تم استخراج وتحويل جميع بطاقات اللعبة الأصلية (1,114 بطاقة) بصورها وتأثيراتها وخصائصها من ملفات اللعبة الأصلية (`card_nameeng.bin`، `card_desceng.bin`، `card_prop.bin`، `list_card.txt`).
   - تحويل كامل للصور إلى صيغ حديثة عالية الدقة وخفيفة الحجم.

4. **الدكات الجاهزة (42 دك)**:
   - تم فك تشفير وقراءة جميع ملفات الدكات الـ 42 الثنائية (`.ydc`) بنجاح:
     - دك يوجي (Yugi Deck)
     - دك كايبا (Kaiba Deck)
     - دك جوي (Joey Deck)
     - دك ماريك (Marik Deck)
     - دك باكورا (Bakura Deck)
     - دك إكسوديا (Exodia Deck)
     - دكات التنانين، أبطال العناصر، الآلات، وغيرها الكثير.

5. **محرك مبارزة متكامل (Duel Engine)**:
   - إدارة كاملة للأدوار والأطوار: Draw ➡️ Standby ➡️ Main 1 ➡️ Battle ➡️ Main 2 ➡️ End.
   - استدعاء عادي (Normal Summon) ووضع دفاعي (Set Monster).
   - استدعاء بالتضحية (Tribute Summon): وحش 5-6 نجوم يحتاج تضحية واحدة، 7+ نجوم يحتاج تضحيتين.
   - بطاقات السحر (Spells) مثل Raigeki, Dark Hole, Pot of Greed, Monster Reborn.
   - بطاقات الفخاخ (Traps) مع تفعيل تفاعلي مثل Mirror Force, Trap Hole, Torrential Tribute.
   - حساب دقيق لأضرار المعارك (الهجوم ضد الهجوم، الهجوم ضد الدفاع، والارتداد، والهجوم المباشر).
   - شروط الفوز المتعددة: تصفير نقاط الحياة (LP=0)، انتهاء بطاقات الدك (Deck Out)، واكتمال قطع إكسوديا الخمسة في اليد (Exodia Win).

6. **ذكاء اصطناعي للعب الفردي (AI Player)**:
   - خصم ذكي يتخذ قرارات تكتيكية في الاستدعاء، التضحية، تفعيل السحر، واختيار أفضل أهداف الهجوم.

## 🚀 طريقة التشغيل والتجربة الفورية

### 1. تشغيل نسخة الموبايل عبر المتصفح / الشبكة المحلية:
داخل مجلد `mobile`:
```bash
npm run start
```
سيفتح التطبيق على المنفذ `3000`. يمكنك فتحه من هاتفك المحمول المتصل بنفس الشبكة عبر كتابة عنوان الـ IP الخاص بجهازك، مثل: `http://192.168.1.X:3000`.

### 2. إعادة استخراج أو تحديث البيانات:
```bash
# استخراج جميع البطاقات
npm run extract:data

# قراءة جميع الدكات الـ 42
npm run parse:decks
```

### 3. بناء تطبيق أندرويد (APK):
داخل مجلد `mobile/android`:
```bash
./gradlew assembleRelease
```
سيتم إنشاء ملف الـ APK النهائي في:
`mobile/android/app/build/outputs/apk/release/app-release.apk`
قم بنقله إلى أي هاتف أندرويد وتثبيته مباشرة.
