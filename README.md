# Yu-Gi-Oh! — Pharaoh's Legacy & Mobile Edition 𓀀

A modern, responsive Yu-Gi-Oh! Dueling experience inspired by the classic Power of Chaos / Yugi Reborn aesthetics, featuring full Arabic card descriptions, authentic audio-visual effects, and real-time multiplayer.

---

## 🌟 Key Features

- **🎮 Responsive Duel Engine**: Full duel field with Monster & Spell/Trap zones, Graveyard, Banished pile, Deck counters, and dynamic Life Points calculation.
- **📜 Complete Arabic Card Database**: Over 770+ cards with localized Arabic names, card types, ATK/DEF, and accurate effect descriptions.
- **⚡ Real-time Multiplayer (P2P / WebSocket)**:
  - Instant room discovery & smooth pairing ritual animation.
  - Rock-Paper-Scissors (حجرة ورقة مقص - Janken) mini-game to determine who plays first.
  - Real-time action syncing across devices on local network or public relays.
- **✨ Authentic Pharaonic Visuals & Audio**:
  - Millennium Eye & Egyptian hieroglyphic theme.
  - Original attack animations, summon effects, and sound effects.
  - Native Fullscreen Mode toggle for immersive mobile and desktop dueling.
- **📦 Deck Library & YDC Parsers**:
  - Includes classic decks and utilities to import `.ydc` deck files.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Running

1. Clone the repository:
   ```bash
   git clone https://github.com/Amr-khalid/Yu-Gi-Oh.git
   cd Yu-Gi-Oh
   ```

2. Navigate to the mobile application directory:
   ```bash
   cd mobile
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

5. Open your browser at:
   ```
   http://localhost:3000
   ```

## 📁 Repository Structure

- `mobile/`: Web and mobile React application with complete duel interface, sound engine, and multiplayer logic.
- `Here are some Decks/`: Curated Yu-Gi-Oh! `.ydc` deck profiles.
- `Deck_Backups/`: Backup deck files and configurations.
- `All Cards - UNLOCKER/`: Card collection unlocking utilities.
- `Shaders/`: Custom graphical shaders for visual effects.
