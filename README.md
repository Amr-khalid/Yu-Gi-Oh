تجربة مبارزة فرعونية أسطورية متكاملة للهواتف الذكية والمتصفح، مستوحاة من سلسلة ألعاب **Yu-Gi-Oh! Power of Chaos (Yugi The Destiny / Yugi Reborn)**، مع دعم كامل للغة العربية، وقاعدة بيانات تضم **1,114 بطاقة** و **42 دك رسمي جاهز**، ومؤثرات صوتية وموسيقية ملحمية، ولعب جماعي محلي وعبر الشبكة (1v1 و 2v2 Tag Team) يعمل بالكامل أوفلاين دون الحاجة لإنترنت.

## 📲 طريقة تحميل وتثبيت تطبيق الأندرويد (APK)

يمكنك تنزيل وتثبيت اللعبة على هاتفك الأندرويد بسهولة تامة عبر إحدى الطرق التالية:

### 🌟 الطريقة الأولى: التنزيل المباشر لملف الـ APK

1. **تحميل ملف التثبيت**:
   * قم بتنزيل ملف **`YuGiOh-Mobile.apk`** مباشرة من رابط التنزيل المتاح داخل اللعبة أو من قسم [Releases](https://github.com/Amr-khalid/Yu-Gi-Oh/releases).
   * حجم الملف التقديري: **127 ميجابايت فقط** (تم تقليص الحجم بأكثر من 80% مع الاحتفاظ بالجودة الفائقة لجميع البطاقات والأصوات والموسيقى وبدون الحاجة لتحميل أي ملفات إضافية).

2. **خطوات التثبيت على الهاتف**:
   * افتح تطبيق **مدير الملفات (Files / Downloads)** على هاتفك.
   * اضغط على ملف `YuGiOh-Mobile.apk` لبدء عملية التثبيت.
   * إذا ظهرت لك رسالة أمان: *"تثبيت تطبيقات غير معروفة (Install unknown apps)"*:
     1. اضغط على **الإعدادات (Settings)** في الرسالة الظاهرة.
     2. فعّل خيار **السماح من هذا المصدر (Allow from this source)** لمتصفحك أو لمدير الملفات.
     3. ارجع خطوة للخلف واضغط على **تثبيت (Install)**.
   * بعد اكتمال التثبيت، اضغط على **فتح (Open)**، وستنطلق اللعبة فوراً بأيقونتها الملكية الجديدة وتعمل 100% بدون إنترنت!

---

### 🌐 الطريقة الثانية: تثبيت اللعبة كتطبيق ويب (PWA) من المتصفح

إذا كنت تلعب اللعبة عبر المتصفح (مثل Google Chrome أو Samsung Internet):
1. افتح رابط اللعبة في متصفح هاتفك المحمول.
2. اضغط على قائمة المتصفح (زر النقاط الثلاث **⋮** في أعلى أو أسفل الشاشة).
3. اختر **"تثبيت التطبيق (Install App)"** أو **"إضافة إلى الشاشة الرئيسية (Add to Home screen)"**.
4. سيتم تثبيت اللعبة على هاتفك كأيقونة تطبيق رسمية كاملة الشاشة بدون شريط متصفح وبدون حواف بيضاء.

## 🌟 أبرز مميزات اللعبة

### 1. 𓋹 أيقونة ملكية جديدة وتصميم أوبسيديان فاخر (v1.1)
* أيقونة تطبيق ثلاثية الأبعاد مبسطة وأنيقة تمثل **عين الألفية الفرعونية (Millennium Eye)**.
* خلفية سوداء داكنة ملكية (`#0c0a08`) ممتدة بالكامل (Edge-to-Edge Full Bleed) بدون أي حواف أو زوايا بيضاء.
* شاشات بدء متطابقة ومظلمة تمنع أي وميض أبيض عند فتح التطبيق.

### 2. ⚔️ محرك مبارزة متكامل وقواعد أصلية (Duel Engine)
* **إدارة كاملة للأطوار**: Draw ➡️ Standby ➡️ Main 1 ➡️ Battle ➡️ Main 2 ➡️ End.
* **استدعاء عادي واستدعاء بالتضحية (Tribute Summon)**:
  * وحوش المستوى 5 و 6 تتطلب تضحية واحدة.
  * وحوش المستوى 7 فما فوق تتطلب تضحيتين.
* **بطاقات السحر والفخاخ التفاعلية**:
  * سحر السرعة العادية والمستمر وتعاويذ الميدان (Raigeki, Dark Hole, Pot of Greed, Monster Reborn).
  * فخاخ دفاعية وهجومية تفاعلية (Mirror Force, Trap Hole, Torrential Tribute, Magic Cylinder).
* **حساب دقيق لأضرار المعارك**: هجوم ضد هجوم، هجوم ضد دفاع مقلوب أو مكشوف، ضرر الارتداد، والهجوم المباشر على نقاط الحياة.
* **شروط فوز متعددة**:
  * تصفير نقاط حياة الخصم (`LP = 0`).
  * نفاذ بطاقات الدك (`Deck Out`).
  * اكتمال قطع إكسوديا الخمسة في اليد (`Exodia Win`).

### 3. 🏟️ نظام ساحات وخلفيات القتال المتطور (Dynamic Battle Arenas)
* أكثر من **18 ساحة قتال أسطورية** فريدة: (معبد الألفية، استاد كايبا كورب، عرين التنين، أعماق أومي، ماتريكس سايبر، قلعة الآلات، أرض الظلال، أهرامات الصحراء...).
* **التحكم في مزامنة الساحة في الأونلاين**:
  * **موحدة ومتزامنة عند الاثنين (موصى به)**: تطابق ساحة القتال 100% بين اللاعبين عبر الشبكة.
  * **مستقلة لكل لاعب**: يرى كل لاعب ساحته المفضلة بحرية دون التأثر بساحة الخصم.
* **التغيير التلقائي التفاعلي لساحة المعركة**:
  * **ثابتة طوال القتال**: تظل الساحة مستقرة تماماً طوال النزال لتوفير أعلى درجات التركيز.
  * **عند نقاط الحسم الحرجة**: تتحول الساحة سينمائياً مع انتقال بعدي واهتزاز فور انخفاض نقاط الحياة إلى منطقة الخطر.
  * **تفاعلية كاملة**: تتحول الساحة تلقائياً مع استدعاء الوحوش الأسطورية العظمى (Gods & Bosses) ومراحل الحسم.

### 4. 🎵 الموسيقى التصويرية وشارات الحماس السبيستونية
* مقطوعات نزال كلاسيكية كورية وأوركسترالية تتغير وتتفاعل مع مجريات المواجهة.
* شارات كرتونية حماسية من كلاسيكيات سبيستون (هزيم الرعد، أجنحة كاندام، داي الشجاع، وغيرها) تنطلق مع مضخم صوت خاص (Preamp Boost) وميزة خفض صوت الموسيقى تلقائياً (Audio Ducking) لتبرز لحظات الحسم.

### 5. 👥 اللعب الجماعي أوفلاين وأونلاين (Local & Online Multiplayer)
* **استكشاف فوري وتلقائي (Zero-Config UDP Discovery)**: بمجرد إنشاء الغرفة، يكتشفها هاتف صديقك تلقائياً عبر حزم بث الـ UDP (منفذ 9002) وتظهر في القائمة بضغطة زر دون كتابة IP.
* **فحص ذكي للبوابات (Multi-Target Auto Probe)**: يدعم جميع شبكات الهوت سبوت والواي فاي العادي والـ Wi-Fi Direct مع التعرف التلقائي على عنوان البوابة (Gateway IP) لضمان الدخول الفوري برمز الـ 4 أرقام.
* **مواجهات فردية (1v1)** أو **نزال فرق ثنائي (2v2 Tag Team)**.
* **إمكانية الاتصال المباشر** عبر نقطة الاتصال المحمولة (Wi-Fi Hotspot) أو البلوتوث أو السيرفر المحلي بدون الحاجة لإنترنت.
* **لعبة قرعة حجرة-ورقة-مقص (Janken)** مدمجة لتحديد من يبدأ أولاً.

### 6. 📚 قاعدة بيانات ضخمة معربة 100%
* **1,114 بطاقة** مستخرجة ومطابقة للأصل مع أسماء وشروحات وقيم هجوم ودفاع باللغة العربية.
* **42 دك رسمي جاهز** مستخرج ومفكوك التشفير من ملفات اللعبة الأصلية (`.ydc`).

## 🚀 تشغيل وتطوير المشروع محلياً

### المتطلبات:
* **Node.js** (إصدار 18 أو أحدث)
* **npm**

### خطوات التشغيل:

1. **استنساخ المستودع وتثبيت الحزم**:
   ```bash
   git clone https://github.com/Amr-khalid/Yu-Gi-Oh.git
   cd Yu-Gi-Oh
   npm install
   ```

2. **تشغيل خادم التطوير السريع**:
   ```bash
   npm run dev
   ```
   سيتم تشغيل اللعبة على: `http://localhost:3000`

3. **إعادة بناء حزمة الأندرويد (APK)**:
   ```bash
   npm run build:apk
   ```
   سيتم توليد ملف APK المحدث داخل المجلد:
   `android/app/build/outputs/apk/debug/app-debug.apk`
